# Phases 5–9: Visual Plan

Read this file before producing output sections 5–9. Follow the output templates exactly. Keep every visual anchored to the timecoded beats established in Phases 1–4, and reference mind-map node ids from Phase 4 wherever a visual idea came from the board.

## Phase 5 — Visual Concept for the Edit

Create the overall visual world for the pre-recorded video. This is not about shooting a new film unless b-roll is required. This is about how the existing recording will be presented.

Define: visual theme; use of original footage; use of b-roll; use of motion graphics; use of text/captions; use of archival or supporting media; camera feel if new b-roll is needed; lighting/color mood; editing energy; graphic style; sound atmosphere.

Output template:

```
VISUAL CONCEPT
- Concept title:
- One-line visual idea:
- How the original recording is used:
- How b-roll supports the message:
- How graphics support clarity:
- Camera style for any new/support footage:
- Lighting style:
- Color palette:
- Mood:
- Editing rhythm:
- Graphic style:
- Sound/music direction:
- Why this concept fits the recorded audio:
```

## Phase 6 — Emotional Arc Mapped to Time

Show how the viewer should feel across the pre-recorded timeline.

Do this:

- Create an emotion curve.
- Mark attention spikes.
- Mark tension rises.
- Mark relief or payoff moments.
- Mark where the viewer should lean in.
- Mark where the edit should slow down or speed up.

Output template:

```
EMOTIONAL ARC
0–3 seconds:
- Time range:
- Spoken content:
- Emotion:
- Viewer state:
- Visual purpose:
- Edit treatment:

3–8 seconds:
...
```

Continue across the full duration. Use segment boundaries that follow the actual speech beats, not a fixed grid.

## Phase 7 — Scene Map for the Pre-Recorded Edit

Turn the transcript/audio into a visual sequence.

For each scene or segment, define: timecode range; script/voiceover content; what is currently on screen from the recording; what should replace or cover it; what b-roll, graphic, text, or cutaway should appear; transition into the next segment; purpose of the segment; risk if the visual is boring or unclear.

Output template:

```
SCENE MAP
Scene 1:
- Time:
- Script/VO:
- Existing media:
- Visual action:
- Overlay/graphic:
- Caption emphasis:
- Transition:
- Purpose:
- Notes:

Scene 2:
...
```

Use a simple flow when helpful: Hook → Problem → Explanation → Proof → Emotion → CTA.

## Phase 8 — Shot and B-Roll Plan

Create a practical plan for visuals over the pre-recorded audio.

Important: this is for editing an existing recording, so do not require impossible new shoots unless the user asks.

For each visual moment, define:

- Shot number
- Timecode
- Script/VO line
- Visual description
- Source type: existing recording, b-roll, screen recording, photo, archive, motion graphic, text animation, AI-generated footage, stock, custom shoot
- Camera angle, if applicable
- Movement, if applicable
- Lens/camera feel, if applicable
- Framing
- Safe zone notes
- Why this shot supports the spoken line
- Alternative option if the first choice is unavailable

Output template:

```
SHOT / B-ROLL PLAN
Shot 01:
- Time:
- Script/VO:
- Visual:
- Source type:
- Angle:
- Movement:
- Lens/camera feel:
- Framing:
- Safe zone:
- Purpose:
- Alternative:
- Notes:

Shot 02:
...
```

Every shot needs an alternative that is achievable with existing assets or a simple graphic. Prefer existing recording first; escalate to b-roll, graphics, archive, screen capture, AI footage, or stock only when the existing material cannot carry the moment.

## Phase 9 — Text Storyboard for the Edit

Since images may not be generated, create a text storyboard detailed enough for an editor or motion designer to build from without further questions.

For each major frame, describe: frame number; timecode; what is visible; what the speaker is saying; what text appears; what graphic appears; camera/subject position; composition; motion direction; emotional tone; transition to next frame.

Output template:

```
TEXT STORYBOARD
Frame 1:
- Time:
- Visual:
- Speaker/VO:
- On-screen text:
- Graphic:
- Composition:
- Motion:
- Mood:
- Next transition:

Frame 2:
...
```

Cover every major visual change, not every video frame. An editor should be able to assemble a rough animatic from this alone.
