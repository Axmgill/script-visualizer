# Output language — simple English

The person reading this plan may not speak English as a first language. They may be a
motion designer in Jakarta, an editor in Cairo, a producer in São Paulo. They will read your
output once, at speed, with a video open in another window. Every sentence they have to
re-read is a sentence that failed.

Simple English is not childish. It is the language of instruction. A pilot's checklist is
simple. A surgical protocol is simple. Simple means *no doubt about what to do next*.

## The one test

**Read the sentence out loud to a colleague. If you would not say it that way, rewrite it.**

Second test, for anything important: translate it in your head into a language you know a
little. If the translation is impossible, the sentence is too clever.

## Rules

**1. One idea per sentence.**
Bad: "The opening sequence should establish the room while also foreshadowing the loss of
meaning that the numbers will later come to represent."
Good: "The first shot shows the room. It is quiet. Later, the numbers stop meaning anything.
This shot plants that."

**2. Average 12 words. Never more than 25.**
Count. If a sentence has three commas, it is three sentences.

**3. Subject, verb, object. Active voice.**
Bad: "The graphic is to be held for a duration of two seconds."
Good: "Hold the graphic for two seconds."

**4. One verb, not a phrasal verb.**
`set up` → build · `carry out` → do · `put together` → assemble · `go through` → check ·
`come up with` → choose · `find out` → learn · `point out` → show · `bring in` → add

**5. Use the common word.**
| Do not write | Write |
|---|---|
| utilise, leverage | use |
| commence, initiate | start |
| approximately, circa | about |
| subsequent | next |
| prior to | before |
| in order to | to |
| ensure | make sure |
| facilitate | help |
| demonstrate | show |
| numerous, myriad | many |
| whilst | while |
| aforementioned | the one above |
| endeavour | try |
| ascertain | find out |
| requisite | needed |
| juxtapose | place side by side |
| elevate, curate, optimise | (say what actually happens) |

**6. One name for one thing, for the whole document.**
Choose the word the first time and never vary it. "Beat" does not become "moment", then
"section", then "block". Variety is a virtue in an essay and a defect in an instruction.

**7. Explain a term the first time you use it, in brackets, in six words or fewer.**
`J-cut (sound arrives before picture)` · `insert (close shot of a detail)` ·
`hold (the frame stops moving)`. Afterwards, use the short word alone.

**8. Never use an idiom.**
Idioms do not translate: *move the needle, low-hanging fruit, in the same breath, on the
nose, kill two birds, boil the ocean, circle back, touch base, at the end of the day.*
Say the literal thing instead.

**9. Numbers.**
Write figures as digits inside instructions: `hold 2 seconds`, `cut at 0:42`, `use 3 shots`.
Write timecodes as `0:42`, never `42s` or `00:00:42:12` unless the software needs frames.
Keep the exact figures from the script: `forty-one boxes` stays `41 boxes` in a table, and
`"forty-one"` only when you quote the speaker.

**10. Instructions: one action per line, starting with a verb.**
```
Cut on the word "meaning".
Hold 2 seconds. No movement.
Add the room sound under it. Low.
```
Not: "It might be worth considering a cut somewhere around the word 'meaning'."

**11. Tables stay thin.** Three to five columns. Header words of one or two words.
If a table needs a paragraph in a cell, the table is wrong — use a list.

**12. No semicolons. No chains of dashes.** One comma per clause, or a full stop.

**13. Say what you are unsure about, in simple words.**
"At 1:32 there is a word I cannot place. I think it is 'receipt'. Check it."
That is better than a confident sentence that turns out to be wrong.

**14. Keep the speaker's words exactly.** Simplify your own sentences, never the quote. If
the script is in another language, keep the quote in that language and give the simple
English in the next line.

## A rewrite, three times

**Original (real, from a plan like this one):**
> The previsualization layer functions as a cognitive scaffold, externalising the argument's
> structural dependencies so that subsequent production decisions may be evaluated against
> the narrative's own evidentiary logic.

**Pass 1 — remove the jargon:**
> The board shows how the argument fits together. It lets later decisions be checked against
> what the script actually proves.

**Pass 2 — shorter, plainer:**
> The board shows how the argument fits together. Each later choice can be checked against
> it.

**Pass 3 — what ships:**
> The board shows how the argument fits together. Build it first.
> Then every later choice has something to point at.

Same meaning. A third of the words. Readable by anyone who can read a recipe.

## Glossary for this skill's own words

Put a short block like this at the top of any long deliverable, so the reader never has to
guess. Define only the words your document actually uses.

| Word | Simple meaning |
|---|---|
| beat | one idea in the script, in order |
| node | one card on the board |
| board | the picture of how the ideas connect |
| anchor | a thing the script names, used as the image |
| carrier | the thing on screen that holds a number |
| claim | something the script says is true |
| proof | the part of the script that supports a claim |
| previz | the plan drawn before the edit is made |
| b-roll | extra footage that is not the speaker |
| insert | a close shot of a detail |
| hold | the frame stays still |
| cut | the change from one shot to the next |
| beat map | the timing of the beats |
| unresolved | not decided yet, and the plan says so |
| style frame | one still image that shows the look |

## Checklist before you send

- [ ] Longest sentence is under 25 words.
- [ ] No sentence needs a second read.
- [ ] Every technical term is explained once, in brackets.
- [ ] One name per thing, all the way through.
- [ ] Every instruction starts with a verb.
- [ ] No idiom, and nothing a translation tool would mangle.
- [ ] The reader knows what to do next without asking.
