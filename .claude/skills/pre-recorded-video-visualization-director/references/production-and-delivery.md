## Phase 16 — Review Checklist

Before finalizing, check the plan itself.

Review for:

- Does every visual support the recorded speech?
- Is the hook strong in the first 1–3 seconds?
- Is the message clear?
- Is the emotion present?
- Are transitions motivated by the audio?
- Are captions readable?
- Are graphics unnecessary anywhere?
- Is pacing matched to attention span?
- Is the ending satisfying?
- Is the plan producible with available assets?
- Does it avoid generic stock-video feeling?
- Does it feel authentic and human?
- Does it fit the platform?
- Does it respect brand/safe zones if provided?
- Does it work as a pre-recorded video, not a live concept?

Output template (mark each Pass / Needs Attention / Missing):


If any item is "Needs Attention" or "Missing", fix the plan or state exactly what input would resolve it.
